# Rule-Based Chatbot Using Python

## Project Title

Rule-Based Chatbot

## Description

This project is a simple rule-based chatbot built using Python. It interacts with users and responds to their messages using predefined keywords and conditional statements.

The chatbot can respond to common greetings, answer simple questions, and provide a fallback response when it does not understand the user's input.

## Technologies Used

- Python 3
- If-elif-else statements
- String handling
- Basic input and output

## Features

- Responds to common greetings.
- Answers simple predefined questions.
- Handles unknown messages with a fallback response.
- Provides a simple text-based conversation.
- Beginner-friendly Python code with comments.

## Setup Instructions

### Requirements

- Python 3 installed on your computer, or Google Colab.

### How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Run the Python file using the following command:

   `python chatbot.py`

Alternatively, upload the Python file to Google Colab and run the code in a cell.
